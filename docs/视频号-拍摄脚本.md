# 视频号拍摄脚本：《给 AI 产品接上嘴》延迟实证

> 目的：用本机正在跑的真实服务（非 AI 生成视频）录一段 ~65 秒短片，证明
> 「2 秒延迟 → 本机栈 0.8 秒体感 / 链路账 284ms」成立。
> 全部数字来自服务端实时账单，可一条命令复现。

## 0. 口径声明（决定视频会不会被打脸——必读）

| 屏幕上出现 | 含义 | 量级（来源） |
|---|---|---|
| 快档 `⏱284ms` | 判停确认 → AI 首音（口径B，p50） | 命中轮 16~31ms，p90 652ms（2026-10-28 真人账单 n=9） |
| chips `判停 500ms` | 你闭嘴后它故意等的静音窗 | conservative 固定档 |
| `体感首音 26ms` | 含预合成语气词 filler | 只抢「以为在等」的体感 |
| 观众手表 | 闭嘴 → 听见 AI | 快档 ~0.8s / 全云 ~1.76s |
| 历史基线 | P0 前 melo 整句合成 | 1966ms → 云流式 1029 → 预热 724 → 现 284 |

**规则**：`⏱284ms` 与 `判停500ms` 必须同屏出现，并配一句旁白：
「284ms 是它算完的时间，那 500ms 是它故意等你、免得抢话的时间。」
绝不说「闭嘴到听见只要 0.3 秒」——观众手表数到的是 ~0.8 秒。

## 1. 前置（已完成可跳过）

- 服务：`localhost:8000` 已在跑（本脚本复核日：cloud / latency 两档均 `session.ready` ✅）
- 浏览器：Chrome（页面 footer 写明仅 Chrome）
- 权限：macOS 系统设置 → 隐私与安全性 → 勾上「屏幕录制」「麦克风」
- 若重启服务，务必用独立账单文件（避免旧轮次污染出账）：
  ```bash
  cd ~/workspace/github/voice-pipeline-mvp
  VOICE_EVENTS_JSONL="$HOME/.voice-pilot/turns-video-$(date +%d%H%M).jsonl" ./scripts/dev_server.sh
  ```

## 4. 录制方式（二选一）

**A. 零安装（最快）**：`QuickTime 播放器 → 文件 → 新建屏幕录制`，**外放、不戴耳机**
（QuickTime 麦克风轨同时录到你的声音 + AI 声音）。音量 ~50%，浏览器 AEC 挡回流、不误触发打断。
**B. 更干净**：OBS 录屏 + **戴耳机** + 系统声音用 ScreenCaptureKit 音频或 `BlackHole 2ch` 采集，
双声道分离、零自激。

## 5. 彩排清单（不录，先跑 2 轮热身清冷启动）

- [ ] 每轮 `⏱` 出现且 < 400ms（偶发 > 600 属正常波动，挑好的 take）
- [ ] 无 `—（未测到）`、无 `（被打断）`（除非是打断演示轮）
- [ ] 句中停顿半秒 AI 不抢话
- [ ] 插话「等一下」AI 立刻停
- [ ] HUD 大号秒表从说话段结束开始跳、首个 AI 音频到达时冻结

## 6. 正式录制（每条一个 take，方便剪）

1. 慢档（cloud）1 轮：「今天上海天气怎么样」
2. 快档基准 3 轮
3. 快档句中停顿 1 轮
4. 快档打断 1 轮
5. 拆解表展开特写
6. （可选）一条最差轮（652ms+）作「波动」证据

## 10. 五个坑

1. 回声自激 → 戴耳机（OBS 路径）；QuickTime 路径务必外放 + 中低音量
2. 冷启动 → 正式录前先热身 2 轮
3. 别用 neural 档（抢话 3/3，被问必崩）
4. 数字用 p50，不挑单点；片尾主动放慢轮
5. 同屏 `判停500` 与 `284` 必须解释，否则评论区抓
